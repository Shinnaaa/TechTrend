## 🧠 AI/ML 前沿论文

**[StateAct: Program State, before Pixels, for Long-Horizon Computer-Use Agents](https://huggingface.co/papers/2607.22798)**
🔬 突破：否定了“截图理解 = 计算机使用 Agent 核心能力”这一假设。通过分离 GUI 子代理（操作像素）与主代理（直接 code 操作 DOM / 文件系统），在 WebArena 长任务 (15+ step) 上成功率达 72%，而同期基于纯截图模型（如 CogAgent）为 41%。
⚙️ 工程影响：MCP 或类似的代码接口协议（如 Playwright 的 page.evaluate）不再是“辅助手段”，而是计算机使用 Agent 的主控制路径。这解释了为什么 Anthropic 在 Computer Use 功能中同时提供 API 和代码执行两类工具——长任务下代码路径的可靠性远超像素操作。

**[Interactive Training 2: Auditable Control Plane for Live Model Training](https://huggingface.co/papers/2607.18314)**
🔬 突破：将训练的人类干预从“改代码后重启”升级为“运行时热更新”，通过训练应用声明式的设置/动作接口，在 checkpoint 保存的安全点动态修改学习率、batch size 等参数，无需中断训练循环。
⚙️ 工程影响：这意味着团队可以用 shared workspace 实现“多人协作调参”，实验变体不再需要三分支代码。对正在大规模跑 ablation study 的团队，可将每次训练配置重载时间从 5 分钟（重启+加载）降至 <1 秒（热更新验证）。

**[DataPrep-Bench: Benchmarking LLMs as Training Data Preparators](https://huggingface.co/papers/2607.20465)**
🔬 突破：建立了一个端到端训练数据质量基准（非人工标注的 surface-level 质量），测试 LLM 从原始数据中构建训练数据 + 通过下游训练效果来评估数据价值的能力。
⚙️ 工程影响：如果你团队用 GPT/Claude 生成 SFT 数据但从未量化“这批数据是否确实提升了模型 X 分”，DataPrep-Bench 的评估框架可直接接入你的数据管道，先对 100 条数据进行 downstream 微调验证，再决定是否大规模生成。

## ⚡ 技术范式变化信号

**[开源权重模型从“护城河争论”升级为“产业联盟战”]**：
Nvidia CEO 公开批评 Anthropic 的禁止立场并组建“开源安全联盟”，OpenAI 内部因拒绝加入爆发冲突。这意味着开源权重的合规化/标准化不再是技术社区内部的讨论，而是变成了 GPU 厂商与 API 供应商的商业角力。**工程决策影响**：如果你的模型部署策略依赖开源权重，应在 2026 Q3 内建立多权重源的备选清单（Qwen / Kimi / 社区微调入口），而非押注单一生态。

**[后Transformer架构的工程化突破窗口]**：
StateAct 等论文系统性地证明了 MCP/代理内代码执行优于纯像素交互，结合 Interactive Training 2 的热更新控制面，2026 年下半年可能出现“非 Transformer 生成引擎（如 SSM/线性注意力）+ 操作系统的 AI Agent 栈”的首次合体。**决策影响**：团队可在 long-horizon Agent 中优先投入“代码接口集成”（如 Playwright/MCP），而非图像理解模型微调，前者在工程上的收益周期更短。

**[数据中心推理的硬件分流（安全专用芯片）]**：
微软的 MAI-Cyber-1-Flash 标志着“专用 AI 芯片”从训练领域（TPU）延伸到推理领域。这不是替代 GPU，而是在**特定延时敏感任务**（网络监控、实时翻译）上分流。**决策影响**：若你的推理服务有 5ms 以下的 P99 延迟需求，不要等 GPU 降价，评估 AMD/Xilinx 或 Marvell 的专用推理卡能否以 1/3 的功耗覆盖当前用 A100 跑的分支。
