## 🧠 AI/ML 前沿论文

**[ExtractBench: A Benchmark for Schema-Guided Enterprise Document Extraction](https://huggingface.co/papers/2607.29677)**
🔬 突破：首个同时评估 value accuracy、record completeness、grounding 和 cost 四个维度的 schema-guided 抽取 benchmark，覆盖 4,869 页、370 份企业文档、8 个业务域、67 种文档类型。此前 benchmark 只测单维准确率，无法反映真实企业场景中"字段缺失"和"证据引用错误"的成本。
⚙️ 工程影响：为 RAG/agent 抽取系统提供了可量化的评估标准——如果团队在做的文档抽取 agent 没有 grounding 评分，这个 benchmark 直接给出缺失的度量维度。

**[Meshy T2: Fast Native Mesh Generation with Flow Matching](https://huggingface.co/papers/2607.28675)**
🔬 突破：用 vertex-set mesh VAE 将网格编码为连续 latent token，配合 flow matching 替代自回归解码，推理速度提升一个数量级（论文报告从秒级降至亚秒级），且消除了自回归的误差累积问题。
⚙️ 工程影响：3D 资产生成从"离线批处理"变为"交互式创作"成为可能——游戏和影视管线中，艺术家可以实时迭代 mesh 生成，而非等待数分钟。

**[From RLVR to RLSVR: Task Transformation Induces Self-Verifiable Rewards for Open-Ended LLM Self-Improvement](https://huggingface.co/papers/2607.23802)**
🔬 突破：将 RLVR（可验证奖励强化学习）从数学/代码扩展到开放域任务，核心方法是任务变换（task transformation）——把开放任务改造成可自我验证的格式，消除对 reward model 和 LLM judge 的依赖，同时规避 judge 偏差和额外推理成本。
⚙️ 工程影响：开放域 RL 训练的成本结构将改变——不再需要训练/部署独立的 reward model，self-verification 直接复用策略网络，推理开销降低约 30-50%。

**[Scaling Properties of Text Conditioning in Visual Generation](https://huggingface.co/papers/2607.29679)**
🔬 突破：发现 diffusion loss 与 prompt 中"结构化语言"的量呈近似线性关系——用 GPG（白盒似然）和 ED（黑盒属性）两个指标量化结构化程度。此前认为 diffusion loss 不随 token 数缩放，这个发现推翻了该假设。
⚙️ 工程影响：文生图模型的 scaling law 可以像 LLM 一样预测——训练前就能预估增加 prompt 复杂度后的 loss 改善，指导数据配比和模型容量决策。
