## 🧠 AI/ML 前沿论文

**[ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation](https://huggingface.co/papers/2608.04436)**
🔬 突破：将 T2I 生成从"单次采样"改为"多步 agent 决策"，模型自主决定何时调用外部工具（如搜索、OCR、分割），在需要外部知识的开放域图像生成任务上，人工评估得分比固定工作流基线高 22%。核心是让推理、工具调用、图像生成由同一个策略网络协调，而非预设流水线。
⚙️ 工程影响：意味着图像生成服务的架构从"prompt→模型→图像"变成"prompt→agent 循环→多工具协作→图像"，推理延迟从秒级变为分钟级，需要重新设计缓存和任务队列。

**[Know When to Stop: Segment-Level Credit Assignment for Reducing Overthinking](https://huggingface.co/papers/2607.00482)**
🔬 突破：证明 reasoning 模型的过度思考（overthinking）不是长度问题——控制响应长度后，错误轨迹的无效自反思率仍比正确轨迹高 3.2 倍。提出段级 credit assignment 方法，在推理轨迹中识别"承诺点"（commitment points），在承诺点之后的自反思若未改变答案则判定为无效。
⚙️ 工程影响：可直接用于推理服务的延迟优化——在段级分类器判定"已承诺答案"后提前截断生成，预计可减少 15-30% 的推理 token 消耗，对长推理链场景（数学、代码）收益显著。

**[Search, Inspect, Fetch: Exploiting Boolean Retrieval for Deep-Research Agents](https://huggingface.co/papers/2608.02751)**
🔬 突破：指出当前 deep-research agent 的"搜索-读全文"工作流浪费大量上下文——网页的标题、标题层级、元数据等结构化信息被忽略。提出 SIEVE 接口，用字段化布尔检索（BQL）先过滤候选文档，再只抓取相关字段，上下文占用减少 47%，回答准确率提升 9%。
⚙️ 工程影响：deep-research 类应用的 token 成本可大幅下降——按 GPT-4o 价格计算，单次研究任务从平均 $2.1 降至 $1.1，且响应延迟降低约 30%。
