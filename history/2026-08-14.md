## 🧠 AI/ML 前沿论文

**[ReRound: Reconstructive Rounding to Resolve Midpoint Ambiguity in Calibration-Free LLM Quantization](https://huggingface.co/papers/2608.11045)**
🔬 突破：标准 RTN 量化在权重接近量化区间中点时，四舍五入方向是任意的，ReRound 用条件扩散模型生成低比特权重的连续重建信号，来引导中点权重的舍入方向。相比 GPTQ 的逐层误差最小化，ReRound 在 4-bit 量化下将困惑度损失从 0.8 降到 0.3（LLaMA-7B 实测）。
⚙️ 工程影响：扩散模型推理开销大，但 ReRound 只在量化阶段运行一次，推理时零额外成本。这意味着 4-bit 量化模型的质量上限被抬高，边缘端部署 7B 模型的可行性提升。

**[From Atomic Evidence to Logical Composition: Structured Compositional Reasoning over Compound Answer Options](https://huggingface.co/papers/2608.12836)**
🔬 突破：LLM 在 AND/OR/NEITHER 复合选项上频繁出错，即使对每个原子判断正确。该框架将复合选项分解为原子答案，用对比假设打分，再用整数线性规划组合分数。在 LOGICAL-COMMONSENSEQA 上准确率提升约 12%。
⚙️ 工程影响：对 RAG 系统的多条件过滤查询（如"找到既懂 Python 又懂 Rust 的工程师"）有直接借鉴价值，但 ILP 求解在实时场景有延迟风险，需评估缓存策略。

**[Ready Cohorts: Bounding GPU Opportunity and Avoiding Host Round Trips in LLM-Agent Control](https://huggingface.co/papers/2608.12123)**
🔬 突破：形式化了 LLM-agent 控制路径中"就绪队列"的概念——模型调用和工具调用之间的小型确定性转换（路由、状态更新）有多少可以留在 GPU 上执行，避免 CPU 往返。在固定分区共享 F 和精确离线份额 P* 的框架下，证明了在零服务时间、无限容量条件下 P* 可精确计算。
⚙️ 工程影响：对 agent 推理框架（如 LangGraph、CrewAI）的部署架构有直接影响——如果路由决策可以留在 GPU 上，agent 的每轮延迟可减少 5-10ms（CPU 往返开销）。这是 agent 推理从"CPU 编排"走向"GPU 原生"的理论基础。
