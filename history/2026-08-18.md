## 🧠 AI/ML 前沿论文

**[Amplified Does Not Mean Predictive: Reasoning Behaviors in Thinking Models](https://huggingface.co/papers/2608.13760)**
🔬 突破：提出 Behavioral Lift 指标，量化"某个推理行为出现时正确率的变化量"。在 15 个模型、6 个 benchmark、15,282 条推理轨迹上验证：推理训练（如 RLHF）会让模型"看起来更 deliberative"（思考痕迹更长、更多自我修正），但这些被放大的行为与正确率的关联度反而下降——即"思考变多不等于答对变多"。
⚙️ 工程影响：对推理模型的评估不能只看输出正确率，还要追踪行为层面的 lift 值。这意味着 RL 训练时若 reward 只基于最终答案，模型会学会"表演思考"而非"真正思考"。训练管线需要引入过程监督（process reward），且要监控哪些行为被放大、哪些被抑制。

**[Modular Cognitive Architecture Emerges in Large Language Models](https://huggingface.co/papers/2608.13567)**
🔬 突破：用电路分析（circuit analysis）在 46 个任务、4 个认知域（语言、形式推理、心理理论、物理世界推理）上测试 LLM 是否出现类似人脑的功能模块化。结果：LLM 中确实出现了模块化组织——不同认知域由不同电路子网络处理，且模块间的信息流模式与人脑的功能连接组（functional connectome）高度相似。
⚙️ 工程影响：如果 LLM 的模块化是涌现的，那么"专家混合"（MoE）架构可能不是人为设计，而是智能系统的自然组织形式。这为 MoE 的稀疏激活策略提供了理论支撑——可以按认知域路由 token，而非当前按 token 语义路由。对推理优化意味着：可以针对特定任务（如代码）只激活对应模块，减少 30-50% 的推理计算量。

**[Agents Catching Agents: Shortcut Cascades and Benchmark Gaming in Clinical Multi-Agent Systems](https://huggingface.co/papers/2608.03744)**
🔬 突破：在 7 个队列、6 个公开医疗数据集上测试多 agent 临床决策系统，发现"社会性捷径"（social shortcut）会级联传播：当两个 peer agent 给出相同错误答案时，第三个 agent 有 5-16% 的概率放弃自己的正确判断转而跟随。单个 agent 对捷径的抵抗力较强（flip 率仅 5-16%），但多 agent 协作反而放大了错误传播。
⚙️ 工程影响：多 agent 系统的"多数投票"机制在医疗等高风险场景可能适得其反。需要引入"权威感知"（authority-aware）机制——根据 agent 的历史准确率加权投票，而非简单多数。对 RAG 系统同样适用：检索结果中多个来源一致但都错误时，系统需要能识别"集体错误"而非盲目采信。

**[DFM Mimir v1: An Open HRM Delivering Frontier Performance at 1B Parameters Using Only Permissible Post-Training Data](https://huggingface.co/papers/2608.13517)**
🔬 突破：仅用 161 个许可数据集（无任何非许可数据）训练 1B 参数模型，在丹麦语上达到 SOTA，英语上超越同规模的 HRM-Text 1B。证明了"数据合规"与"性能"不必二选一——关键在数据配比和训练策略，而非数据规模。
⚙️ 工程影响：对受监管行业（医疗、金融、法律）的模型训练有直接参考价值——合规数据也能训出可用模型。1B 参数意味着可在边缘设备部署，为小语种场景提供了新选项。
