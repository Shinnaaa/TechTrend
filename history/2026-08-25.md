## 🧠 AI/ML 前沿论文

**[Hydra-0: Action Flow for Generalist World Modeling and Control](https://huggingface.co/papers/2608.18077)**
🔬 突破：将机器人动作表示为像素运动（action flow），统一了世界模型在跨本体、跨任务、跨环境下的动作表征——相比 action-conditioned baseline，机器人运动误差降低 90.4%，物体运动误差降低 60.2%；在 RoboLab benchmark 上达到 r=0.96 的 Pearson 相关性。
⚙️ 工程影响：动作即像素的设计意味着视频生成模型可以直接作为机器人控制器的世界模型使用，无需为每个机器人平台单独训练动作编码器；零样本组合和低数据适配能力使新任务接入成本从"重新训练"降为"提供少量演示视频"。

**[SparsePR: Training-Free Sparse Attention for Video Generation and World Models](https://huggingface.co/papers/2608.18484)**
🔬 突破：指出 block-sparse attention 的 partition 几何形状同时影响 pooled support 和残差可预测性，提出 Response-Coupled Partitioning + Probe-Fitted Residual Reconstruction 组合，使采样查询在保持生成质量的同时跳过大量注意力计算。
⚙️ 工程影响：训练无关的稀疏注意力直接可插拔到现有视频生成模型推理管线，对长视频生成（>10s）的显存和延迟优化有直接价值；无需微调即可部署，适合作为视频生成服务的推理加速层。

**[ParaTempo: Efficient Parallel Reasoning via Temporal Confidence](https://huggingface.co/papers/2608.16425)**
🔬 突破：用时间置信度替代 final-answer consensus 和局部 token 置信度作为并行推理分支的动态控制信号——现有方法在推理中途无法判断分支是否值得继续，ParaTempo 通过异步框架在推理过程中实时评估分支质量，提前终止低置信分支。
⚙️ 工程影响：对推理成本敏感的生产环境（如 API 服务）可直接降低并行推理的平均分支数，在保持准确率的同时减少计算开销；训练无关特性使其可叠加在现有推理模型之上。

**[PhysCaP: Physics-Informed Code-as-Policy Agent](https://huggingface.co/papers/2608.21031)**
🔬 突破：在 code-as-policy 框架中增加物理信息探索层，使机器人通过主动交互（推、戳）估计物体质量和刚度，而非被动观察——从机器人本体感觉（proprioception）提取物理属性，无需额外传感器。
⚙️ 工程影响：解决了 VLA 策略在未知物理属性物体上的操作失败问题；对抓取、堆叠等需要力控的操作任务，物理属性估计模块可独立部署为预处理层，提升下游策略的泛化能力。
