## 🧠 AI/ML 前沿论文

**[LLaDA-Image: Building Strong Image Generators with Fully Open Training Recipes](https://huggingface.co/papers/2609.03796)**
🔬 突破：把扩散语言模型（LLaDA）直接复用到图像生成——6B DiT 从头训练，先做纯图像预训练（220M 样本中 98 个为真实图像）再接入视觉语言模块，打破了过去"生图必须从配对图文数据起步"的假设。训练中用无参数 RMSNorm + Muon 优化器替代 AdamW，Muon 在 6B 规模下把优化器显存占用降约 50%。
⚙️ 工程影响：训练管线被拆成 image-only 预训练 + 后期对齐两阶段，意味着没有高质量图文对的小团队可以先用海量公开图像预训练，再在少量配对数据上微调；Muon 优化器若在 6B DiT 上验证有效，值得在自家视频生成预训练中替换 AdamW 做一次对比实验。

**[Rethinking On-Policy Distillation of LLMs II: One Training Example](https://huggingface.co/papers/2609.04172)**
🔬 突破：把 on-policy distillation（学生生成轨迹 + 老师逐 token 监督）压缩到数据极限——只用一个 query 训练，学生性能竟能持续提升数百步并恢复 full-data OPD 的大部分增益。解释是：单 query 的 on-policy  rollout 天然覆盖训练中访问到的状态分布，且学生向老师对齐的速率快于分布漂移。
⚙️ 工程影响：如果单 query 即可逼近全量蒸馏效果，那主流蒸馏管线（动辄百万级指令数据）的采集成本可显著压缩。验证路径：用内部 10 万条指令集蒸馏出一个 7B，再只用其中 1 条蒸馏一次，对比两者在 5 个下游任务上的差距——若差距 <15%，说明数据多样性对 OPD 的边际收益被高估。

**[Principia: Relational Physics Tests for Video Models](https://huggingface.co/papers/2609.04200)**
🔬 突破：用"同一场景两物体运动必须满足物理关系"替代绝对运动测量，绕开了帧率、物体尺度、相机标定等干扰因素，构建了覆盖重力、碰撞等 8 类物理现象的评测基准。此前视频模型的物理推理评测（如 CLEVRER）依赖标注和标定，结果不可比。
⚙️ 工程影响：视频生成模型（Sora 类）的物理一致性从此有了可自动打分的指标——同一画面内两球的加速度比应恒定，无需外部标定即可定量评估。做视频生成评测基础设施的团队可直接复现该关系式检测器，用于自家模型的回归测试门禁。

**[LatentPress: Context Compression Beyond Text and Vision](https://huggingface.co/papers/2609.01507)**
🔬 突破：把长上下文压缩成"连续记忆 token"，冻结的 decoder 通过 input-embedding 接口直接读取，推理时无需重建文本——压缩 4-16 倍，仅训练一个 4.2M-26.2M 参数的 adapter（约为 decoder 的 0.1%）。在 LongMemEval 上达到 0.504 准确率（7.7 倍压缩）。
⚙️ 工程影响：对比传统 context distillation 输出文本摘要或图片压缩，LatentPress 的压缩产物是连续向量，意味着 token 预算中不再需要为"压缩后的文本"预留可读格式开销。对长对话缓存/多轮 agent 记忆系统有直接价值；但 adapter 与具体 decoder 绑定，换模型需重新训练。

**[Environment Evolution for Terminal Agents](https://huggingface.co/papers/2609.04128)**
🔬 突破：不从头合成新环境，而是用"渐进难化"策略——在已有环境上迭代施压，使环境始终保持在模型当前可学习的前沿。这解决了 co-evolution 方法（依赖 on-policy rollout）在模型变强后学习信号衰减的问题。
⚙️ 工程影响：终端 agent 后训练（terminal agent post-training）的环境成本被显著压缩——不再需要为每个新模型重新合成环境，而是维护一个动态难化的环境池。做 agent 训练数据管线的团队值得读：环境复用率 ↑ 意味着合成预算可重新分配。
