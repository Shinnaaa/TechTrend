## 🧠 AI/ML 前沿论文

**[When Models Edit Too Much: On the Fidelity of Minimal Code Edits](https://huggingface.co/papers/2609.04061)**
🔬 突破：在 400 个 BigCodeBench 问题上注入 AST 级破坏构造已知最小补丁，发现前沿模型（含 GPT-5.5）普遍过度编辑——Pass@1 高不代表补丁最小化，修复正确但重写范围远超 bug 本身。
⚙️ 工程影响：代码审查工具不能只看"测试是否通过"，需增加 diff 最小性指标；对依赖 LLM 生成 patch 的 CI 流水线，过度编辑会放大 review 成本并引入回归风险。

**[MaxKernel: Agentic Kernel Generation for TPUs](https://huggingface.co/papers/2609.04523)**
🔬 突破：多 agent 系统实现 TPU kernel 自动生成，三种范式（HITL、Auto、Graph-Based）覆盖从协作设计到全自动优化的完整谱系，用实时编译器反馈驱动迭代。
⚙️ 工程影响：TPU kernel 开发从"周级专家手工调优"压缩到"小时级 agent 自动搜索"，对依赖 TPU 的大规模训练团队，kernel 优化的人力成本可降低一个数量级。

**[RISE: Recursive Improvement via Self-Extrapolating Policy Distillation](https://huggingface.co/papers/2609.05295)**
🔬 突破：用模型自身 RLVR 轨迹构造合成 teacher——在参数空间外推当前 checkpoint 与锚点的位移，解决 on-policy distillation 中外部 teacher 分布不匹配和自蒸馏受限于上下文学习能力的问题。
⚙️ 工程影响：后训练不再依赖外部强 teacher 或人工标注，模型可从自身轨迹持续提升，这对 RLVR 训练的成本结构是根本性改变——省去 teacher 推理的算力开销。

**[Don't Drop Dropout: Optimizing Layer Sparsity for Efficient LLM Training and Inference](https://huggingface.co/papers/2609.05275)**
🔬 突破：系统量化 layer dropout 在 SOTA LLM 训练中的效果，推翻"dropout 降低精度"的既有结论，证明优化后的 layer sparsity 可同时加速训练、提升精度并增强对 zero-shot layer pruning 的鲁棒性。
⚙️ 工程影响：预训练配方中重新引入 layer dropout 可减少训练 FLOPs，同时产出更易压缩的模型——对推理部署意味着更小的 pruning 精度损失。

**[Group Adaptive Clipping Policy Optimization](https://huggingface.co/papers/2609.00444)**
🔬 突破：识别 GRPO 固定 clipping 边界的问题——难题的稀有正确 rollout 和易题的丰富正确 rollout 被同等裁剪，但前者携带更强的探索梯度信号，却被不成比例地抑制。
⚙️ 工程影响：RLVR 训练中按 group 成功率自适应调整 clipping 边界，可提升难题解决率——对数学推理和代码生成任务的 RL 后训练有直接收益。
