## 📌 今日要闻

**1. Claude Haiku 5.5 发布：OSWorld 计算机操作从 15.7% 跳到 72.4%，token 价格降幅最高 90%**
OSWorld 是真实桌面操作基准，15.7→72.4 意味着 Haiku 档位从"能聊天"变成"能替你点鼠标"，这是 agent 产品第一次可以在小模型上跑 GUI 自动化而不烧钱。但新 tokenizer 每任务消耗更多 token，实际账单降幅小于标称的 90%——按 token 单价做预算的团队要重算。 · [HN](https://www.anthropic.com/claude-haiku-5-5) / [The Decoder](https://the-decoder.com/claude-haiku-5-5-arrives-with-massive-price-cuts-proving-the-ai-pricing-arms-race-is-far-from-over/)

"边想边答"把首 token 延迟从"完整推理后"提前到"推理中"，44% 是用户可感知的量级。付费层 GPT-6 Sol / 免费层 GPT-6 Luna 的双档命名说明 OpenAI 把能力分层做进了模型名，而不是靠限速区分。 · [HN](https://openai.com/index/gpt-6-for-everyone/) / [The Decoder](https://the-decoder.com/chatgpt-with-gpt-6-ditches-mostly-text-output-for-interactive-ui-with-charts-buttons-and-mini-apps/) / [TechCrunch](https://techcrunch.com/2026/10/07/chatgpt-is-getting-a-lot-more-visual-with-the-launch-of-a-new-interface/)

**4. Google SynthID 检测器公开，1800 亿条内容已带水印**

**5. Chrome 开始发布 JPEG XL 支持**
Chrome 2019 年移除 JPEG XL 支持后，社区靠 flag 续命六年。这次是正式发布，意味着图片 CDN 可以开始按 Accept 头做 JXL 分发——同画质下比 AVIF 编码快、解码省电，但 Safari 和 Firefox 的支持状态决定你能不能真的省掉 WebP 回退。 · [HN](https://developer.chrome.com/blog/jpeg-xl-in-chrome)

## ⚡ 趋势信号

**决策模型从生成模型里独立出来，一周内三家云厂商入场**：Cloudflare Clef、AWS Strands Decider 2B、Google 相关动作集中在 10 天内，说明"路由/审核/风险打分"这类单 token 分类任务正在被拆成专用小模型，而不是拿 70B 生成模型硬跑。如果你的架构里还有"用 GPT 判断该走哪条链路"的环节，本周值得测一下 Clef 这类 open-weight 决策模型的自托管成本。
> 延续 10-02 的 Cloudflare Clef 信号，今天没有新增厂商，但 Haiku 5.5 的 OSWorld 跳升说明"小模型做判断"这条线在同步推进。

**GUI agent 的模型门槛被 Haiku 5.5 拉低一个数量级**：72.4% 的 OSWorld 分数意味着 GUI 自动化不再需要 Opus/GPT-6 级别模型，Haiku 档位就能跑。这会直接改变 agent 产品的成本结构——之前因为单步成本太高而放弃 GUI 自动化的团队，本周该重跑一遍自己的任务集。
> 这是新出现的信号，与 10-03 Apple 收紧 Full Disk Access 形成对冲：模型能力够了，但 OS 权限在收紧。

### 🧠 AI/ML 论文
- **[DLoop: Looped Speculative Decoding](https://huggingface.co/papers/2610.07659)**：现有投机解码在每个 drafting stage 后强制验证，即使 draft model 全部命中也要跑一次 target forward。DLoop 让 drafting 在验证前继续，减少 target 模型前向次数——对高接受率的 draft model 场景直接降延迟。
- **[SkillForge: Co-Evolving Skills and Agents via Dynamic Skill Lifecycles](https://huggingface.co/papers/2610.09832)**：给 agent 的 skill library 加了 trial/active/stable/retired 四态生命周期，解决"技能只增不减、过时技能误导 agent"的问题。做 memory-augmented agent 的团队可以直接借鉴这个淘汰机制。
- **[SWE-Game: Can Coding Agents Build the Games We Want?](https://huggingface.co/papers/2609.33678)**：247 个任务、41 个可执行 Godot 参考游戏、13 类玩法，含 83 个注入故障修复和 Godot→Unity 移植。这是第一个用可执行游戏引擎状态做验证的 coding agent 基准，比 SWE-bench 的测试通过率更接近真实交付。
