# 每日技术情报简报 · 2026-11-09

## 📌 今日要闻

**1. Goldman Sachs 把 Claude Code 从交易员和银行家手里收回，HN 669👍**
这是首个大型金融机构公开撤回编码 agent 的案例，理由不是模型能力而是合规与审计边界——受监管岗位的代码变更需要可追溯的责任人，agent 生成的 diff 无法满足。对在金融、医疗等受监管行业推 agent 的团队，这条把"agent 能不能写生产代码"变成"agent 写的代码谁签字"，本周该做的是把 agent 输出纳入现有变更审批流而不是另开一条通道。 · [The State of AI](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers)

**2. 阿里 Co-Design Bench：GPT-6 Astra 在真实用户请求上只完整解决 26.4%，旧基准同模型 99%+**
基准用的是"实际把 agent 卡住过的真实请求"，不是合成任务。26.4% 与 99% 的落差说明现有 SWE-bench 类评测已经失去区分度，任何按旧基准分数做选型的决策都需要重跑。对正在评估 Ripple-65B、mini-swe-agent 这类方案的团队，这是本周唯一该看的数字——先确认你的评测集里有多少是"真实失败过的请求"。 · [The Decoder](https://the-decoder.com/ai-coding-agents-still-need-human-cleanup-on-nearly-three-out-of-four-tasks-in-a-real-world-test/)

**3. Karpathy 用 Claude Opus 5.5 一个周末把 4300 万条 HN 评论筛成 6,454 个视频，称效果超过 YouTube 推荐**
单次长上下文批处理 + 结构化筛选，一个人两天完成过去需要推荐系统团队数月的工作。可复现的部分是"用 LLM 做离线内容策展"这条流水线：43M→6.4K 的压缩比意味着每千条评论约 0.15 个产出，成本可算。对做内容检索或知识库的团队，值得抄的是它的筛选 prompt 结构而不是结果。 · [The Decoder](https://the-decoder.com/andrej-karpathy-built-a-curated-video-platform-in-a-weekend-using-claude-and-20-years-of-hacker-news/)

**4. llama-modchip：284B 的 DeepSeek 在 64GB 内存、无 GPU 上跑起来，HN 388👍**
把 284B 模型塞进 64GB 消费级内存，靠的是权重分块 + 按需从磁盘换入，代价是吞吐。这条的实际价值不是"能跑"，而是给出了一个可复现的 offload 实现，让本地部署的显存门槛从"多卡"降到"大内存单机"。对在评估私有化部署的团队，先测它的 token/s 再决定是否值得替代 API 调用。 · [GitHub](https://github.com/synchopate/llama-modchip)

**5. Nvidia 董事会调查黄仁勋与疑似中国间谍 Alice Huang 的关系，黄承认婚外情**
CEO 层面的安全事件，Megaspeed 高管被指受中国国安部招募对 Nvidia 进行情报活动。对采购 Nvidia 算力或与其有供应链关系的团队，短期影响是出口管制与合规审查可能收紧，长期看是 AI 芯片供应链的政治风险溢价。 · [TechCrunch](https://techcrunch.com/2026/11/08/nvidia-says-its-investigating-ceo-jensen-huangs-relationship-with-possible-chinese-spy/) / [The Verge](https://www.theverge.com/ai-artificial-intelligence/1029562/nvidia-investigating-jensen-huang-relationship-chinese-spy)

## ⚡ 趋势信号

**编码 agent 的评测标准正在从"能不能做"转向"做完谁负责"**：Goldman 撤回 Claude Code 和 Co-Design Bench 的 26.4% 是同一件事的两面——能力已经够用，卡点在责任归属和真实任务成功率。选型时把"审计链路"和"真实失败集通过率"放进评估表，比看 SWE-bench 分数有用。
> 延续 11-05 OpenAI 收购 Pierre（agent 直推主干的权限模型）和 11-08 apiiro 的凭证泄漏扫描——三件事都指向 agent 进入生产后的治理缺口，不是新信号，但今天有了金融业的第一个撤回案例。

**本地推理的内存门槛在下降，显存门槛没变**：llama-modchip 的 284B/64GB 和 ISTA-DASLab 的 DeepSeek-V4.1-Flash Coder GGUF 同时出现，说明社区在往"大内存单机 + 量化"方向挤。私有化部署的成本模型该按"内存带宽"而不是"显存容量"重算一遍。
> 延续 11-07 Ripple-65B 的 Apache 2.0 全权重发布——可私有化的 coding 模型供给在增加，瓶颈从"有没有权重"变成"跑不跑得动"。
