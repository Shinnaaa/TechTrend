## 📌 今日要闻

**1. Grok Build 编码 agent 泄漏 3.5 万个应用的机密数据，部分属于 SpaceX**
研究员发现 35,000 个 Grok Build 应用对任何扫描到的人完全开放，泄漏内容含机密信息。这是 11-08 apiiro 报告 Claude Code 把凭证写进 1,122 个公开仓库之后，第二起编码 agent 默认配置导致的数据外泄——两次都不是模型能力问题，是 agent 的默认权限边界问题。任何把 agent 部署成"应用"形态的团队，今天该做的是扫一遍自己 agent 服务的鉴权中间件。 · [Ars Technica](https://arstechnica.com/security/2026/11/grok-build-coding-agent-leaks-oodles-of-confidential-info-some-belonging-to-spacexsi/)

**2. Google 发布 Gemini 4 Carbon，多项 benchmark 超过 Fable 5.2，单任务成本不到一半**
距 Fable 5.2 发布仅一天，Google 就把 GA 版本推出来，且 The Decoder 明确写了"在部分基准上领先 Fable 5.2，每任务成本不到一半"。同时预览 `/swarm` 协调式 agent 团队功能。对昨天刚把 Fable 5.2 写进路由表的团队，成本模型需要重算——但注意"部分基准"没说是哪些，先跑自家任务再改默认模型。 · [The Decoder](https://the-decoder.com/gemini-4-carbon-arrives-just-in-time-to-feel-like-yesterdays-news-in-the-fastest-model-cycle-yet/)

**3. Fable 5.2 在真实自由职业任务上完成率 41%，一年前是 2.5%**
这个数字来自真实付费任务而非合成基准，和 11-09 报道的 Co-Design Bench"真实请求只解决 26.4%"是同一类评测的两种口径。41% 意味着接近六成的真实工作仍需人工收尾——如果你的自动化 ROI 模型假设 agent 完成率超过 80%，这个数字直接推翻它。 · [The Decoder](https://the-decoder.com/anthropics-fable-5-2-completes-41-percent-of-real-freelance-jobs-up-from-2-5-percent-a-year-ago/)

**4. 纽约州 AI 安全法生效，OpenAI、Anthropic 须注册、披露安全实践、上报重大事故，否则罚款**
首个州级强制披露制度落地，要求的是"注册 + 安全实践披露 + 事故报告"三件事。对在这些模型上构建产品的团队，意味着上游供应商的事故披露会成为你的事件响应输入——你的 on-call runbook 里需要一个"等供应商披露"的分支。 · [TechCrunch](https://techcrunch.com/2026/11/10/openai-anthropic-face-new-oversight-as-new-yorks-ai-safety-law-takes-effect/)

**5. Anthropic 把 Claude 扩成完整工作区：Sheets、Whiteboards、Interactive Connectors，Adobe/Atlassian 应用可嵌入**

## ⚡ 趋势信号

**编码 agent 的安全问题从"模型输出"转移到"默认配置"**：一周内三起（Claude Code 凭证写入、Grok Build 3.5 万应用裸奔、Chainalysis 全客户凭证失窃含 AI agent 参与），全部与模型能力无关，全部是 agent 的默认权限和默认持久化路径。工程决策上的直接影响：agent 部署评审清单里，"默认鉴权"和"默认写盘路径"要独立成项，不能并进"模型选型"评审。
> 延续 11-08 的 apiiro 报告和 11-07 的 Chainalysis 事件，今天 Grok Build 是第三例，模式已稳定。

**模型发布周期压缩到以天计，选型流程跟不上**：Fable 5.2（11-10）→ Gemini 4 Carbon（11-11）间隔一天，且后者成本不到前者一半。按季度做模型选型的团队，选完就已经落后一个版本；需要的是"可替换的评测 harness"而不是"选定的模型"。
> 新出现的信号，与 11-10 的 Fable/Mythos 双版本发布形成连续。
