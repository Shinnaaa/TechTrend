## ⚡ 趋势信号

**编码 agent 的竞争焦点从"能力"转向"权限边界与合规审计"**：本周三起独立事件（Goldman 收回 Claude Code、Grok Build 泄漏 3.5 万应用、Chainalysis 全员凭证失窃）指向同一件事——agent 的默认权限模型比模型分数更决定它能不能进生产。选型评估表里该加一栏"agent 可写路径清单"，而不是继续比 SWE-bench。
> 11-08 apiiro 报告 Claude Code 把凭证写进 1,122 个公开仓库 → 11-09 Goldman Sachs 因审计边界收回 Claude Code → 11-11 Grok Build 泄漏 3.5 万应用。三天内从"配置失误"升级到"机构撤回"，是加速而非延续。

**开源权重模型的"单点打穿"策略开始奏效，但只在 coding 场景**：Ripple-65B（11-07）用 3200 万美元做出 TerminalBench 美国开源第一，其他 benchmark 一般；今天 NVIDIA 连发 SkillEvaluator/SkillSpector 两个 agent skill 评测框架，说明"skill 质量"正在成为独立于模型权重的可交易资产。私有化部署的评估重点从"模型够不够强"变成"skill 库够不够全"。
> 11-07 Ripple-65B Apache 2.0 全权重 → 今日 NVIDIA SkillEvaluator 单日 +108 星。评测基础设施先于模型成熟，是生态分工的信号。
