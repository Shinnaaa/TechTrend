### 🧠 AI/ML 论文
- **[The Value of Thinking: Learning When to Reason in Hybrid Decision Models](https://huggingface.co/papers/2611.16961)**：提出 zero-or-T thinking——单模型要么一次前向直接出答案（零 token），要么完整推理（T token），由轻量自路由块选择。相比现有 adaptive reasoning（只缩短推理长度）省掉的是全部输出 token，对高 QPS 分类/路由环节的推理成本影响直接。
- **[Back to Pixels: Lifting Latent Video Diffusion into Pixel Space](https://huggingface.co/papers/2611.17336)**：PixVid 保留预训练 latent 视频模型的 DiT，改为逐帧在像素空间生成，解决 VAE 时空压缩导致的分辨率翻倍 token 四倍、条件只能作用于帧组、响应需等整个帧块的问题。
- **[Who Remembers What? Multi-Granularity Memory Extraction for Multi-User, Multi-Agent Interaction](https://huggingface.co/papers/2611.10439)**：MixUA 把用户-agent 轨迹蒸馏成 lesson，并按受益范围和披露风险分配到 user-agent 对 / 单用户 / 单 agent / 全局四级作用域——多租户 agent 共享记忆时的隐私边界问题，此前没有明确的分级方案。
