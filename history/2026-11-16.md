## ⚡ 趋势信号

**非 Nvidia 训练链路从"能跑"进入"能打"**：LongCat-2.5 在 Terminal Bench 拿到 88.4，说明昇腾集群已经能训出第一梯队 agent 模型，而不只是推理替代。对工程决策的直接影响：2027 年算力预算里，"国产卡"从备选项变成需要认真做 PoC 的选项，尤其是 agent 类负载。
> 这是新出现的信号。过去 7 天的 Nvidia 报道集中在治理与合规风险（CEO 辞职、出口调查、投资收缩），没有一条给出"替代硬件训出同级模型"的实证；今天这条补上了技术侧的证据。

**AI 生成代码的合规边界正在被监管方而非模型方划定**：Goldman 收回 Claude Code（11-09）、澳洲央行观察到 15-24 岁软件岗位招聘下滑、国会收紧芯片出口，三件事指向同一方向——受监管场景对 agent 输出的追责要求会先于模型能力成熟。本周该做的是把 agent 生成的 diff 接入现有审批流，而不是新开一条通道。
> 延续 11-09 的信号，但今天多了澳洲央行的劳动力数据作为第二来源佐证。
