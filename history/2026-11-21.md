**2. Signal 在 iOS 27 / Android 上屏蔽截图，明确针对 Apple Siri AI、Gemini Intelligence、Meta Muse 读取私聊**
Signal 官方博客把设备级 AI agent 称为"生存威胁"，并承认 macOS 端防护不完整。这是第一个主流通讯应用把"agent 读屏"当作攻击面来防——对做移动端 agent 或屏幕理解的团队，意味着截图/无障碍 API 这条数据通路会在更多应用上被切断，agent 的输入源需要重新设计。 · [Signal](https://signal.org/blog/protecting-your-privacy/) / [The Decoder](https://the-decoder.com/signal-blocks-screenshots-on-ios-27-and-android-to-stop-ai-agents-from-reading-private-chats/)

**3. OpenAI 把 GPT-6.2 推理链提取成功率从 54% 压到 0.2%，同时暂停数千至数万账号**
自适应红队测试下的数字，说明 reasoning trace 泄露是可量化的攻击面而非理论风险。对自建推理服务的团队，这条给出的是基线：如果你的模型暴露了 reasoning 输出，需要按同样方法做一次提取测试，而不是等供应商修。 · [The Decoder](https://the-decoder.com/openai-makes-it-much-harder-for-attackers-to-extract-how-its-latest-ai-models-think/)

**4. 研究者向 AI 供应链植入 200 万个可追踪"金丝雀"秘密，发现数据大规模外泄**
用唯一可追踪的 prompt 秘密做溯源，证明用户数据在 AI 供应链里不会保持私有。对任何把敏感数据送进第三方模型 API 的团队，这是可复现的审计方法：给每条敏感请求打唯一标记，再在下游日志/训练集里搜。 · [Ars Technica](https://arstechnica.com/security/2026/11/a-leaky-ai-supply-chain-is-exposing-secret-user-data-at-an-alarming-rate/)

**5. Nvidia 拟以至少 5 亿美元收购成立两年的扩散语言模型公司 Inception，补强开源 Nemotron**
扩散式生成（非逐 token）路线第一次被大厂用收购背书。对推理栈选型的影响：如果 Nemotron 后续版本走扩散路线，现有基于自回归假设做的 KV cache / 投机解码优化会失效，值得在架构评审里留一个分支。 · [The Decoder](https://the-decoder.com/nvidia-bets-at-least-500-million-on-inceptions-diffusion-models-to-strengthen-its-open-source-nemotron-lineup/)

## ⚡ 趋势信号

**Agent 读屏能力正在被应用层主动封堵**：Signal 屏蔽截图、Apple 同时自建 agent 又抬高竞品接入门槛，设备级 agent 的数据获取从"系统 API 默认可读"转向"应用逐个授权"。做移动 agent 的团队本周该把输入源假设从"能截屏"改成"需要应用配合"，并评估无障碍 API 的可用性风险。
> 延续 11-16 至 11-20 的 agent 越界主线（加州起诉 OpenAI、OpenAI 内部 agent 密送邮件），今天新增的是防守方开始行动，而非新的越界事件。

**推理链保护成为模型供应商的显式指标**：OpenAI 把提取成功率做成可公布的百分比（54%→0.2%），意味着 reasoning trace 泄露会被纳入供应商安全对比表。选型时该问的不再是"是否暴露 reasoning"，而是"提取成功率是多少、用什么红队方法测的"。
> 新出现的信号，与 11-18 GPT-6.2 发布同源，但保护措施是今天才披露。
