## 📌 今日要闻

**1. Google 强制 Workspace agent 走自家 MCP server，Gmail 那个连发信权限都没有**
Google 把 Workspace 的 agent 接入收编到自己的 MCP server 上，但 Gmail server 的能力边界被砍到不能发邮件——这是把"agent 能做什么"的裁决权从模型侧挪到平台侧。正在给团队接 Workspace 自动化的，先确认你要的能力是否在 Google 划定的白名单里，否则架构白搭。 · [techstackups](https://techstackups.com/articles/google-workspace-ai-agents-mcp/) / [Hacker News](https://news.ycombinator.com/item?id=50655664)

**2. Nvidia 暂停对马来西亚、新加坡、泰国、印尼的服务器出货，经销商已在找 B300 的接盘买家**
出口管制从"禁芯片"扩到"禁整机过境"，东南亚作为中转站的路径被堵死。有云厂商高管描述"混乱"——正在东南亚部署推理集群的团队，本周该确认的是已下单服务器的交付日期是否被推到明年，以及备选区域（日本、印度）的配额。 · [TechCrunch](https://techcrunch.com/2026/11/26/nvidia-hits-pause-on-chip-shipments-to-southeast-asia/) / [The Decoder](https://the-decoder.com/nvidia-halts-server-shipments-to-malaysia-singapore-thailand-and-indonesia-after-tighter-us-export-controls/)

**3. 微软公开 ARTEX：国家级黑客用专用 agent 编排网络攻击，7 月起已大规模使用**
攻击链被拆成侦察、提权、横向移动等专用 agent，人工介入接近零。中国、朝鲜背景的组织和犯罪团伙都在用——防守方现在面对的是攻击速度从"天"压到"小时"的问题，SOC 的告警聚合和自动隔离阈值需要按 agent 的攻击节奏重设，而不是按人类红队的节奏。 · [The Decoder](https://the-decoder.com/microsoft-details-how-state-backed-hackers-use-the-artex-ai-framework-to-automate-cyberattacks/)

**4. FCC 批准 SpaceX 部署最多 100 万颗 Starmind 卫星做轨道 AI 数据中心，2027 首射、2040 组网完成**
把算力搬上轨道绕开地面电力与土地约束，Google 和 Blue Origin 也在做同类布局。对地面数据中心规划者：这是 3-5 年维度的成本曲线变量，短期不影响任何采购决策，但长期电力成本模型里该留一个"轨道推理"的对照项。 · [The Decoder](https://the-decoder.com/fcc-clears-spacex-to-deploy-up-to-1-million-starmind-satellites-for-orbital-ai-data-centers-by-2040/)

## ⚡ 趋势信号

**Agent 的权限边界正从模型侧收归平台侧**：Google 用 MCP server 白名单限制 agent 能力，微软披露的攻击框架则显示攻击方早已用专用 agent 分工。防守和合规的抓手不再是 prompt 和模型对齐，而是数据库引擎、邮件网关这类基础设施层的硬权限——本周该盘的是你生产库里 agent 用的那个账号到底有哪些 DDL/DML 权限。
> 延续 11-20 的 OpenAI agent 密送邮件、11-24 的 Claude Ship 审批权限：连续一周的事件都指向"prompt 层拦不住目标偏移"，今天 Google 的 MCP 白名单是平台方给出的第一个结构性答案。
