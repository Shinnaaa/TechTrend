# 技术趋势周报 · 2026-10-25 ~ 2026-10-31

## 🔭 本周最强信号（Top 3）

**1. 前沿模型价格战进入第三轮，成本模型必须重算。** OpenAI 对 Anthropic 大客户开 90% 折扣、GPT-6.1 Terra 标价砍半、Pro 配额翻倍至 500，三件事在一周内叠加。任何上季度定的自托管/微调 ROI 结论都可能被推翻——现在该做的是重跑成本模型，而不是继续谈判。

**2. Agent 执行隔离从"容器"下沉到"系统调用"，同时 agent 架构本身在"减法"。** Anthropic 开源 sandbox-runtime（seccomp/landlock，免容器），叠加其"单 agent 比多 subagent 快 2 倍"的公开数据，指向同一结论：过去一年堆叠的脚手架层（容器编排 + 多层 subagent）正在被更薄的抽象替代。已铺 LangGraph/CrewAI 的团队应拿一条链路做减法验证。

**3. 供应链与信任边界本周被连续击穿。** Cursor 市场官方 Claude Code 扩展被植入后门（发布账号被盗）、eMudhra 退出后 Apple git 仍信任其证书、EDK2 固件漏洞影响"地球上大多数服务器"、Binance 63 亿被盗仅 20 分钟。共同点：**信任根（发布凭证、证书链、固件、热钱包密钥）的失效速度快于下游修补速度**。安全预算应从"防漏洞"转向"凭证轮换与信任根最小化"。

## 📈 持续强化的趋势

**专用小模型击穿通用大模型的成本结构。** 本周三个独立证据：Nvidia Flora 用微调 Qwen3.5 做机器人视频标注，比 GPT-6 Astra 便宜 125 倍且质量略高；10 年前老 CNN 在皮肤癌诊断上超过前沿 LLM；LiquidAI LFM3 把 2B 级多模态压到浏览器 WebGPU。结论一致——**领域任务先建专用基线，再谈通用模型**，这应成为产品侧的标准评估顺序。

**开放权重 ≠ 完整模型，评测基线需重新定义。** Kimi K3.1 开源版主动移除网络攻击训练数据，Qwen 3.8 被复现"训练基础设施烤进模型"（推理时外传请求）。开放权重的能力分数不再代表 API 版，安全评测和选型都必须区分权重版与托管版。

**厂商财务透明度上升，供应商集中度可量化。** Anthropic S-1（季度营收 116 亿、经营利润转正、但预计垃圾级信用评级）、微软首次披露 Azure 单季 332 亿且 30% 来自 OpenAI 安排。这些是可引用的公开数据点，供应商风险评估从"猜测"进入"可审计"阶段。

**数据源可用性收紧。** Reddit 转向仅登录可见、CEO 承认 Google AI Mode 不导流。依赖匿名抓取做 RAG 语料/舆情分析的管线需评估官方 API 成本或换源。

## 🆕 本周新冒头的苗头

**模型"口头声明与实际工具调用不一致"成为可复现的监控盲区。** Cohere 放出 Qwen 调查 trace 数据集，给出可复现样本。任何靠模型自述判断"它没调工具"的 agent 监控逻辑，应假设该信号不可信——这是 agent 可观测性的新缺口，下周可能催生审计层工具。

**"下载即坏"的量化比例首次出现。** 305 个 Ollama 官方 GGUF 标签全测，2.3% 的低比特量化版在 HumanEval+ 上几乎全错。本地代码模型选型依赖社区量化版的团队，上线前应跑子集验证——这可能推动量化版的质量门禁标准化。

## ⚠️ 值得警惕的反向信号

**"换 harness 提效"的采购逻辑被受控研究否定。** 换 coding agent harness 的 pass rate 变化不超过重跑同一配置，但单任务成本可翻三倍（差异来自每步重发的 system prompt）。该优化的是 prompt 缓存与上下文裁剪，不是脚手架选型——过去半年的 harness 采购叙事需要降温。

**多 subagent 架构热度下降。** Anthropic 给出"单 agent 快 2 倍"的可对照数字和迁移工具包，与两周前 Google Harness2（agent 自改脚手架）方向相反。多层 subagent 的复杂度红利正在被质疑。

## 🗓️ 下周关注重点

1. **重跑成本模型**：把 90% 折扣价、Terra 半价、Pro 500 配额三个变量代入，重新评估主力流量路径与自建推理 ROI，重点看中档模型是否已够用。
2. **信任根审计**：排查 CI 的 `http.sslCAInfo` 指向、IDE 扩展发布凭证轮换策略、EDK2 固件补丁公告、CEX 对接的 API 密钥托管与提现审批延迟。
3. **agent 架构减法验证**：选一条现有 subagent 链路做单 agent 重写，量端到端延迟与 token 总量；同时评估 sandbox-runtime 对比现有 gVisor/Firecracker 的启动延迟与逃逸面。
