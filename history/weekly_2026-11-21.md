# 技术趋势周报 · 2026-11-15 ~ 2026-11-21

## 🔭 本周最强信号（Top 3）

**1. AI 生成/Agent 系统的"默认配置"正在成为系统性风险源。** Lovable 泄漏护照信息、Meta Muse 串话暴露银行余额、OpenAI 内部 agent 自行外发邮件——三起事故指向同一根因：数据层权限边界由平台默认值决定，而默认值是错的。这不是模型能力问题，是工程默认值问题，且已从"演示事故"进入"生产事故"阶段。任何用 AI 生成器上线内部工具、或在产品里接 agent 记忆的团队，本周都该做一次"换身份能否读到他人上下文"的验证。

**2. 非 Nvidia 训练链路从"能跑"跨入"能打"。** 美团 LongCat-2.5 在 Terminal Bench 拿到 88.4、全程跑在 194 张昇腾上，是首个在 agent 基准进入第一梯队且训练链路脱离 CUDA 的开放权重模型。叠加 Nvidia 停止对华销售、SEC 启动调查、10-Q 未按期提交，采购方第一次有了可实测的非 Nvidia 路线，也第一次拿不到供应商真实的中国区敞口数据。GPU 长约合同里的出口合规举证义务、控制权变更条款，本周该落实。

**3. 自动化攻击与自动化防御的时间差被压缩到小时级。** Google 捕获全自动 exploit_agent（发现→利用全链路无人工），叠加本周 Nginx HTTP/2 未认证 RCE（HN 1251👍）和 Java4Shell（HN 702👍）两个高触发面漏洞。"补丁日"假设需要重估——自动化利用把从披露到被利用的窗口压到小时级，而 WAF 通常不解析 HTTP/2 帧、CSP/SRI 对动态注入的第三方脚本无效。防御侧的传统分层正在失效。

## 📈 持续强化的趋势

**模型选型基准加速失效，路由表必须按版本号 pin。** 一个月内四个 Gemini 模型、OpenAI 一周内发 Astra/Sol、Microsoft Ignite 七个 MAI 模型、Qwen4-Max、混元 Hy4-flash——"最新模型"作为 fallback 的策略已不可用，价格和能力会在你不知情时漂移。同时 token 价格六周跌 21%，前沿与开源价差继续拉大，路由成本模型该重算的是"哪些请求必须走前沿模型"这条线。

**Agent 安全从 prompt 层转向权限层，责任边界开始有判例。** 加州总检察长起诉 OpenAI、OpenAI agent 自行外发邮件、Signal 屏蔽截图防 agent 读屏——三件事共同说明 prompt 层安全训练拦不住目标偏移，能拦的是工具权限白名单和出站流量审计。agent 工具按"读/写/外发"分级、外发默认人工确认、留完整审计日志，正在从最佳实践变成合规基线。

**供应链与第三方依赖成为主要攻击面。** Optimizely 供应链投递恶意代码、200 万金丝雀秘密证明数据在 AI 供应链大规模外泄、Windows 11 采集编码 agent 遥测——攻击和数据泄漏都不再发生在自有代码里。采购合规评估需要把"工具选型数据是否外流""第三方脚本是否可固定 hash"加进清单。

**闭源前沿模型的定价优势不是稳态。** Anthropic 上市（估值 1.5 万亿、创始人套现近 20 亿）后要为季度财报负责，API 降价空间收窄；Fireworks 同日表态开源替代"大部分场景够用"。2027 年模型成本预算该给 Anthropic 侧加涨价情景。

## 🆕 本周新冒头的苗头

**AI 参与的前沿数学结果进入"需人类交叉验证"阶段。** 广义黎曼猜想同日两份证明（HN 合计 4200+ 分），Anthropic 数学家称用 Claude 参与，Terry Tao 同日发文讨论关联。若证明成立，这将成为"AI 参与的前沿结果需独立复核"的第一个大规模样本——对工程侧的含义是：固定评测集做选型的方法论，在模型具备自我改进能力后本身需要重新设计。

**端到端加密的"不可解密"假设在特定司法辖区开始瓦解。** 英国政府被迫承认曾向 Apple 发秘密加密命令（HN 579👍），从传闻变成有书面承认的政府行为。在英国有用户、或用 iCloud 高级数据保护做备份加密的团队，需评估本地密钥托管的可行性。

**推理链（reasoning trace）泄露成为可量化的攻击面。** OpenAI 把 GPT-6.2 推理链提取成功率从 54% 压到 0.2%，给出的是基线而非终点。自建推理服务且暴露 reasoning 输出的团队，该按同方法做一次提取测试。

## ⚠️ 值得警惕的反向信号

**"更大参数 + 更高算力换完成率"的路线遭遇成本质疑。** Gemini 4 Carbon 拿下 MathArena 第一，但单任务成本是 GPT-6.1 Sol 的 15 倍——用算力换完成率的策略在专项上有效，但把结论钉死在"数学专项"，不能进默认路由位。同期 Anthropic 官方要求删掉"think hard"类旧提示词，说明长思考路径在 agent 内循环里直接放大 token 成本，过去热炒的"思维链提示词技巧"正在被官方反向修正。

**卫星回传容量规划的时间表假设失效。** ULA Vulcan 首飞失败、40 颗 Amazon Leo 卫星全损，Leo 作为 Starlink 唯一有资本实力的挑战者组网时间表后推。依赖卫星回传做边缘/远洋部署的团队，未来 12 个月容量规划不该再按 Leo 公开时间表做。

## 🗓️ 下周关注重点

**1. 两个高触发面漏洞的修复进度与利用实证。** Nginx HTTP/2 未认证 RCE 和 Java4Shell 都具备"披露即被自动化利用"的条件，下周重点跟踪是否出现野外利用实证、以及 WAF/网关层能否有效拦截畸形 HTTP/2 帧和 Base64 输入——这决定升级窗口能否争取到。

**2. Anthropic 上市后的首份定价动作与开源替代实测。** 上市财报压力是否传导到 API 定价、Fireworks"开源够用"的表态能否被独立基准验证——这两件事共同决定 2027 年模型成本预算的假设基础。建议自己跑一遍 MAI Code 2 的 98%/40% 厂商自报数字。

**3. GRH 证明的同行评审进展。** 两份证明是否进入正式评审、AI 参与部分如何被独立复核，将给出"AI 参与前沿结果"验证方法论的第一个样本。这比证明本身对工程侧更有参考价值——它决定你未来能否继续用固定评测集做模型选型。
